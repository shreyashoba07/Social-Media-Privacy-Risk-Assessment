# Privacy by Design

- **Data minimization:** the questionnaire asks whether information is public, never the actual phone number, email, address, birthday, password, or private messages.
- **Purpose limitation:** answers are used only to calculate an educational privacy-awareness result.
- **Least privilege:** no social-media login or account permission is requested.
- **Privacy by default:** no raw answers are stored by this starter.
- **Transparency:** scoring logic, categories, and limitations are documented.
- **User control:** users choose answers and may use a fictional demo.
- **Retention limitation:** no assessment database is enabled by default.
- **Secure processing:** input IDs are validated; only local development origins are allowed by CORS.
